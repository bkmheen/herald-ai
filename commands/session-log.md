이번 세션에서 수행한 작업을 **일자·시간 순서의 "차례"(시간별 작업 설명)** 로 정리하여 **화면에 표시**하십시오.
**파일은 생성하지 않습니다.** (`/session-save` 가 동일 내용을 `HERALD_LOG_DIR`(기본 `~/Desktop/`) 에 저장합니다.)

이 명령의 목적은 `/session-save` 로 저장될 기록의 **차례 부분을 미리 보는 것**이며, 동시에 추린 결과를 **상태 파일로 남겨 `/session-save` 가 그대로 이어받게** 하는 것입니다.

## 0. 필터 조건 (인자)

- 이 명령의 인자: `$ARGUMENTS`
- **인자가 있으면** 그 조건에 맞는 작업만 추려서 표시합니다. (예: `테스트를 제외한 개발 관련 업무` → 개발 작업만, 테스트는 제외)
- **인자가 비어 있으면** 전체 작업을 표시합니다 (필터 없음).

## 1. 먼저 수집

- **작업 디렉토리**: `pwd` 로 현재 절대경로를 구하고, git 저장소면 `git branch --show-current` 와 이번 세션 커밋(`git log --since=... --date=format:'%m-%d %H:%M' --pretty=format:'%cd | %s'`)으로 시각을 보강하십시오.
- **세션 작업 내역**: 대화 전체를 되짚어 이번 세션에 실제로 한 일을 **일자·시간 순서**로 정리하십시오(커밋 시각을 앵커로). 추측 금지 — 실제 한 일만.

## 2. 카테고리 태그 (필수)

각 작업 항목에 아래 **표준 카테고리** 중 하나를 부여하십시오. 필터는 이 태그를 기준으로 결정론적으로 적용합니다.

| 태그 | 범위 |
|------|------|
| `개발` | 기능 구현·코드 작성·리팩터링 |
| `버그` | 버그 수정·디버깅·원인 분석 |
| `테스트` | 테스트 작성·실행·검증(QA) |
| `문서` | 문서·주석·기록·README 작성 |
| `리서치` | 조사·분석·검토·비교 |
| `git` | 커밋·브랜치·머지·푸시·배포 |
| `설정` | 환경·설정·도구·의존성 구성 |
| `기타` | 위에 맞지 않는 작업 |

- 한 항목이 둘 이상에 걸치면 **주된 성격** 하나를 고르되, 애매하면 `기타`로 두지 말고 가장 가까운 태그를 선택합니다.
- **필터 해석**: 인자의 자연어를 위 태그의 **포함(include)/제외(exclude)** 집합으로 환산하십시오.
  - 예: `테스트를 제외한 개발 관련 업무` → include={개발, 버그}, exclude={테스트}
  - 포함 집합이 비면 "제외 외 전부"로 간주합니다.

## 3. 화면 출력 형식 (이 순서로 표시)

```
🗂  세션 작업 차례 — [{작업디렉토리 basename}]
작업 디렉토리: {절대경로}
브랜치/저장소: {git 정보(있으면)}
일시: {시작 일시} ~ {끝 일시}
필터: {인자 원문 또는 "없음(전체)"}  →  포함 {태그…} / 제외 {태그…}

요약 (개괄)
- {시간대} — 1. A 작업 · 2. B 작업 · 3. C 작업

작업 목록 (일자·시간별, 필터 적용 후)
1. ({MM-DD HH:MM}) [{태그}] {작업명}
2. ({MM-DD HH:MM}) [{태그}] {작업명}
   … (시간 순)
```

- 필터로 **제외된 항목 수**가 있으면 목록 끝에 한 줄로 `(필터로 N건 제외됨)` 표기.
- 필터 결과가 **0건**이면 목록 대신 "조건에 맞는 작업이 없습니다"라고 표시하고, 상태 파일은 빈 목록으로 기록합니다.

## 4. 상태 파일 기록 (인계용 — 필수)

표시를 마친 뒤, 추린 결과를 인스턴스별 상태 파일에 기록하십시오. `/session-save` 가 이 파일을 읽어 동일 범위로 저장합니다.

```bash
source ~/.claude/skills/task-tracker/scripts/instance-resolve.sh
# cwd 해시를 키로 결합 — 동시 세션(다른 디렉토리)이 같은 RUNTIME_DIR 로 수렴해도 충돌 없음
CWD_HASH=$(printf '%s' "$PWD" | shasum -a 256 2>/dev/null | cut -c1-12)          # macOS·대다수 Linux
[ -z "$CWD_HASH" ] && CWD_HASH=$(printf '%s' "$PWD" | sha256sum 2>/dev/null | cut -c1-12)  # Linux(coreutils)
[ -z "$CWD_HASH" ] && CWD_HASH=$(printf '%s' "$PWD" | md5sum 2>/dev/null | cut -c1-12)      # Linux 폴백
[ -z "$CWD_HASH" ] && CWD_HASH=$(printf '%s' "$PWD" | md5 2>/dev/null | cut -c1-12)         # macOS 폴백
[ -z "$CWD_HASH" ] && CWD_HASH="default"
STATE="$RUNTIME_DIR/.session_log_state__${CWD_HASH}.json"
cat > "$STATE" << 'STATE_EOF'
{
  "cwd": "{절대경로}",
  "git": "{git 정보 또는 빈 문자열}",
  "period": "{시작 일시} ~ {끝 일시}",
  "filter_raw": "{인자 원문 또는 빈 문자열}",
  "filter_include": ["{태그}", ...],
  "filter_exclude": ["{태그}", ...],
  "items": [
    {"time": "{MM-DD HH:MM}", "category": "{태그}", "title": "{작업명}", "detail": "{한두 줄 핵심 — 배경→조치→검증}"}
  ]
}
STATE_EOF
echo "상태 파일 기록: $STATE"
```

> 충돌 방지: 상태 파일명은 **현재 작업 디렉토리(`cwd`)의 해시**를 키로 포함합니다. 백그라운드 잡과 포그라운드 세션이 같은 상위 `claude` 프로세스를 공유해 동일 `RUNTIME_DIR` 로 수렴하더라도, **서로 다른 디렉토리에서 일하면 상태 파일이 분리**되어 인계가 오염되지 않습니다. (같은 디렉토리의 동시 세션은 여전히 공유 — 그 경우 `/session-save` 에 인자를 직접 주십시오.)
>
> 이 명령은 herald-ai 의 `task-tracker` 스킬(`instance-resolve.sh`)에만 의존합니다. herald-ai 설치본이라면 추가 설정 없이 동작합니다.

- `items` 에는 **필터 적용 후 남은 항목만** 넣습니다. `detail` 은 `/session-save` 의 "세부 내용" 작성을 돕기 위한 핵심 메모입니다.
- JSON 값 안에 큰따옴표·줄바꿈이 들어가면 escape 하십시오. (heredoc 은 `'STATE_EOF'` 로 따옴표를 묶어 변수 치환을 막되, 내용 자체는 유효한 JSON 이어야 합니다.)

## 5. 작성 원칙

- **표시 + 상태 파일 기록까지만 한다 — 저장 디렉토리에 파일은 쓰지 않는다.** 저장은 `/session-save` 의 역할.
- **요약(개괄)** 과 **작업 목록(일자·시간별)** 두 부분을 모두 표시한다. "세부 내용"은 상태 파일의 `detail` 에만 담고 화면에는 생략.
- 시간 순서·실제 한 일만. 커밋이 있으면 시각·해시를 작업명에 병기.
- 표시 끝에, 파일로 남기려면 **`/session-save`** 를 실행하면 같은 필터 범위로 저장된다고 한 줄 안내한다.
