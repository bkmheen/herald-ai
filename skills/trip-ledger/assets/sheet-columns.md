# 시트 열·서식 스펙 (복사용)

절차와 이유는 `playbooks/20-sheets.md`. 여기는 **그대로 붙여 쓰는 값**만 둔다.

## 영수증 시트

헤더 행(4행)에 붙여넣을 값 — 탭 구분:

```
날짜	요일	시각	도시	장소	분류	금액(EUR)	원화금액(KRW)	결제수단	주요내역	UID	원본메모파일	구글맵 지도그룹명	세부분류	추정사항
```

| 열 | 이름 | 폭(px) | 서식 |
|----|------|-------:|------|
| A | 날짜 | 95 | |
| B | 요일 | 34 | |
| C | 시각 | 50 | |
| D | 도시 | 85 | |
| E | 장소 | 220 | |
| F | 분류 | 70 | |
| G | 금액(현지) | 85 | `#,##0.00` |
| H | 원화금액(KRW) | 95 | `#,##0` |
| I | 결제수단 | 110 | |
| J | 주요내역 | 340 | |
| K | UID | 150 | |
| L | 원본메모파일 | 300 | |
| M | 구글맵 지도그룹명 | 135~290 | 목록명만 |
| N | 세부분류 | 150 | |
| O | 추정사항 | 265 | 30~40자 이내 |

- 틀고정 **4행**
- H열 수식: `=ROUND(G5*INDEX(GOOGLEFINANCE("CURRENCY:EURKRW","close",A5),2,2))`

## 기타결제 시트

```
날짜	요일	구분	항목	거래처	통화	금액	원화금액(KRW)	결제수단	예약·승인번호	비고	UID
```

| 열 | A | B | C | D | E | F | G | H | I | J | K | L |
|----|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 폭(px) | 85 | 34 | 85 | 340 | 95 | 50 | 85 | 100 | 110 | 105 | 470 | 150 |

- 틀고정 **4행**, G·H 는 `#,##0`
- 서식은 손으로 만들지 말고 영수증 시트 `A1:L4` 복사 → **서식만 붙여넣기**

## 머리말 3행 템플릿

```
1행: <워크북명> — <시트명>
2행: 건수 N건 · 합계 €X (원화환산 Y원 · 결제일별 환율 합) · 기간 YYYY-MM-DD ~ YYYY-MM-DD
3행: ※ 새 영수증은 5행 이후 맨 아래에 이어서 추가 · 중복 방지는 K열 UID 대조(같은 UID가
     있으면 추가·수정하지 않음) · H열 원화금액은 결제일 종가 환율(GOOGLEFINANCE) 자동 환산 ·
     분류는 <N종 나열> · M열 「구글맵 지도그룹명」은 구글맵 목록명만 기재하고, 추정 근거·부가
     메모는 O열 「추정사항」에 기록 · 원본에 없는 값은 최선의 가정으로 확정하고 「(추정)」·
     「(가정)」처럼 괄호로 근거를 표기
```
