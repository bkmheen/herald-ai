# 10 · 영수증 → 볼트 노트 → 앤솔로지

> ⛔ **이 단계는 서버 맥 전용이다.** 리모트 맥에서는 읽기만 하고, 수정은 SKILL.md §5 인계 프로토콜로 넘긴다.

## 노트 배치

```
Dossier/Archive/<대분류>/<소분류>/YYMMDD-요일 [영수증]-HHMM <장소> <내역> <금액>.md
```

- 대분류 예: `문화`(음식·미술·여행) · `쇼핑`(식품·화장품·기타) · `행정`(교통) · `재정`(수수료) · `업무`(출장)
- 분류가 애매하면 `_Unclassified` 에 두고 나중에 옮긴다. 억지로 배정하지 않는다.

## frontmatter 필수 필드

| 필드 | 용도 |
|------|------|
| `uid` | `UID_XXXXXXXXXX` — **중복 방지의 유일한 키**. 시트에도 이 값을 싣는다 |
| `title` | 파일명과 동일 |
| `location` | **구글맵 등록의 원천**. 상호 + 주소. 없으면 지도 등록 단계에서 특정 불가 |
| `status` | 진행 상태 |

`location` 이 비어 있으면 30-maps 단계에서 반드시 막힌다. 영수증 정리 시점에
주소를 확보해 두는 것이 전체 파이프라인에서 가장 비용이 싸다.

## 앤솔로지(링크그룹) 편입

여행 1건 = 앤솔로지 노트 1개 (`note_kind: link-group`).

```
Dossier/Anthologies/AN_개인/YYMM00 <여행명> 비용기록.md
```

- 본문의 `<!-- LINK_GROUP_BEGIN -->` ~ `<!-- LINK_GROUP_END -->` 블록에
  개별 지출 노트 링크가 나열된다. 이 블록은 **엔진이 생성·갱신**하므로 손으로 고치지 않는다.
- 앤솔로지가 곧 시트 한 장의 모집단이다. 시트 건수와 링크 건수는 일치해야 한다.
  불일치하면 둘 중 하나가 누락된 것이다 — 먼저 **UID 대조**로 찾는다.

## 지도 등록 마커

지도 등록을 마치면 각 노트 본문 끝에 남긴다.

```
[MAPS_REGISTERED] <노트 uid> -> "<구글맵 목록명>" / <장소명>
```

이 마커가 있으면 다음 작업에서 재등록을 건너뛴다.
**볼트 쓰기이므로 서버 맥에서만** 기록한다.

## 미러 (서버 맥에서 작업을 마친 뒤)

볼트를 수정했으면 반드시 미러를 돌린다. 안 돌리면 다른 맥이 옛 상태를 본다.

```bash
$VAULT_MIRROR_CMD
```

- 이 맥이 미러 원본이 아니면(심볼릭 링크) 스크립트가 스스로 skip 한다.
- 다른 미러가 실행 중이면 락 충돌로 skip 되지만, **진행 중인 미러가 내 변경분을 전파**한다.
- 대표 변경 파일이 **미러 수신본** 쪽에 반영됐는지 확인하고 보고한다.
