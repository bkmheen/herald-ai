# 30 · 구글맵 장소 목록 등록

> 어느 맥에서나 가능하다(클라우드). **단, 노트에 마커를 남기는 일만 서버 맥 전용.**

## ⛔ 먼저 읽을 것

**구글 지도 장소 카드의 「저장」 버튼을 클릭하려 하지 마라.** 대화상자가 뜨지 않는다(L-004).
좌표·ref·리로드·DOM 조작 모두 실패로 확인됐다. 아래 검증된 경로로 직행한다.

## 목록 이름 규칙

여행 1건 = 목록 1개. 이름은 **시트 M열에 적히는 값과 글자 하나까지 동일**해야 한다.

```
<지역> <연도> <성격>          예) 마스트리히트 2026 국제학회 Optica ImageSense
                              예) 델프트 2026 여름
```

## 절차

### 1) 대상 목록 만들기 — 사전 준비

시트 M열에서 등록 대상 장소를 뽑고 **중복을 제거**한다. 같은 가게에서 여러 번 결제했으면
지도에는 1건이다. `location` 이 비었거나 `(상호 미상)` 인 행은 제외한다.

### 2) 현재 목록 상태 확인 — 먼저 조회, 나중에 등록

이미 들어 있는 장소를 등록하려 애쓰지 않도록 **먼저 목록을 읽는다.**

```
https://www.google.com/interests/saved/list/<컬렉션 id>
```

시트가 「미등록」이라고 말해도 그대로 믿지 않는다. **지도 쪽이 정본**이다.
(시트 표기가 낡아 실제로는 등록돼 있던 사례, 반대로 정말 없던 사례 둘 다 있었다.)

### 3) 장소별 저장 — 검증된 경로

구글 **검색**에서 `<상호> <도시>` 로 검색해 지식패널을 띄우고,
`assets/maps-save-via-search-kp.js` 를 실행한다.

- 스니펫은 **멱등**이다. 이미 체크돼 있으면 건드리지 않고 상태만 돌려준다.
- 반환값의 `title` 로 **엉뚱한 가게를 저장하지 않았는지** 매번 확인한다.
- 한 배치에 **1~3건**만 넣는다(L-006). 타임아웃이 나면 재실행 말고 상태를 조회한다.

### 4) 동명 업체 가리기

같은 상호가 여러 지점일 때는 임의로 고르지 않는다. `LESSONS.md` L-007 의 절차
(우편번호 구역 · 직전·직후 결제 시각 · 도보 거리)로 확정하고,
확정 근거를 **시트 O열 「추정사항」에 짧게** 남긴다.

### 5) 등록 후 — 마커 (서버 맥 전용)

```
[MAPS_REGISTERED] <노트 uid> -> "<구글맵 목록명>" / <장소명>
```

리모트 맥이라면 여기서 멈추고 SKILL.md §5 인계 프로토콜로 넘긴다.
**지도 등록 자체는 이미 끝났다는 사실**을 지시서에 명시해 서버 맥이 재등록하지 않게 한다.

## 알려진 부작용

지정 목록에 저장하면 기본 「저장됨」 목록에도 함께 들어간다(L-005).
작업 후 사용자에게 보고하고, 정리 여부는 물어본다. 임의로 지우지 않는다.
