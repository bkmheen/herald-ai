## 커밋·버전 규약 — v3.1.0

이 저장소는 **규약 v3.1.0** 을 따릅니다. **정본은 herald-ai 저장소의
`docs/COMMIT-CONVENTION.md`** (그 맥의 clone 경로 — 예: `{{CONVENTION_DOC}}`) 이고,
아래는 이 저장소에 적용된 요약입니다. 충돌하면 정본이 우선합니다.
정본이 없는 맥에서도 **아래 요약만으로 커밋할 수 있도록** 필요한 규칙은 여기에 다 적혀 있습니다.
사용자가 **"v3.1 커밋 체계"** 라고 하면 정본의 「호출됐을 때 할 일」 7단계를 수행합니다.

### 버전

```
patch = 묶음 × 10 + 커밋          0.1.10 = 묶음 1 · 커밋 0
                                  0.1.247 = 묶음 24 · 커밋 7
```

**맨 뒤 한 자리가 커밋, 그 앞이 전부 묶음.** 묶음 상한 없음.

| 자리 | 올리는 주체 |
|---|---|
| `major` | 사용자 지시 |
| `minor` | 사용자 허락 (Claude 는 근거를 들어 요청만) |
| 묶음 | Claude 자체 판단 — **커밋 9 도달 시 강제 전환** |
| 커밋(일의 자리) | 커밋마다 +1 |

- 묶음의 첫 커밋은 `x0` · minor 가 오르면 patch 는 `10` 부터 (`x.y.0~x.y.9` 는 미정의 구간)
- zero-padding 금지 · 버전은 단조 증가 · **소급 재번호 금지**
- 현재 버전의 단일 출처는 [`VERSION`](VERSION). 다른 문서에 숫자를 옮겨 적지 않습니다

### 커밋

- **사용자 명시 요청 시에만** 커밋합니다. 자체 판단 커밋 금지.
- **한 커밋 = 하나의 논리 변경** (문서 ↔ 코드, 플랫폼별, 빌드 산물은 분리)
- 제목: `v<버전> [<slug>] <한국어 요약>` · 본문: **원인 → 조치 → 검증** · HEREDOC (`git commit -F -`)
- 트레일러: `Co-Authored-By: Claude <모델명> <noreply@anthropic.com>`
  {{TRAILER_NOTE}}
- 금지(사용자 요청 없이): `--amend` · `--no-verify` · `--no-gpg-sign`.
  pre-commit 실패 시 `--amend` 로 덮지 말고 **새 커밋**을 만듭니다.

### 커밋 동반 필수 작업

1. `CHANGELOG.md` — Keep a Changelog 형식 (`Added`/`Changed`/`Fixed`/`Removed`/`Verified`)
2. `VERSION` — 버전 증가
3. `DEVLOG.md` — 배경·의사결정 기록. `x0` 커밋이면 "현재 묶음" 줄 갱신
4. **검증** — 이 저장소의 검증 명령을 돌리고 결과를 `Verified` 에 적습니다.
   돌리지 않은 것을 "완료" 라고 적지 않습니다

### push

- **사용자 명시 요청 시에만.** 자동 push 금지.
- 언급 전 `git remote -v` 로 가능 여부를 확인합니다.
- 브랜치를 push 하면 앞선 미푸시 커밋이 함께 올라갑니다 — 그런 경우 무엇이 함께 갔는지 보고합니다.
- `--force` · main force push 는 추가 재확인.
