# template_2609 — pptx 기본 템플릿

> **특별한 지정이 없으면 모든 pptx 를 이 템플릿으로 만든다.**
> 어느 LLM 이 만들든 같다. 다른 점은 「AI 사용 내역」에 적히는 모델 이름뿐이다.

- 이름의 `2609` 는 이 서식이 정리된 시점(2026년 9월)이다
- 규칙의 근거: `.llm/memory/30_산출물_및_버전_규칙.md`

## 쓰는 법 — 세 줄

```bash
cp .llm/templates/template_2609/template_2609.py  "<번호>. <제목>_v0.1.py"
cp .llm/templates/template_2609/template_2609.md  "<번호>. <제목>_v0.1.md"
# .py 맨 위 상수 여섯 줄을 고치고, 내용은 .md 에 쓴다
python3 "<번호>. <제목>_v0.1.py"
```

`.py` 에서 고치는 것은 **여섯 줄뿐**이다.

| 상수 | 뜻 |
|---|---|
| `NUMBER` | 자료 번호 (`.llm/memory/25_번호_규칙.md`) |
| `TITLE` | 제목 — 파일명과 머리말에 함께 쓰인다 |
| `VERSION` | 버전 — 표지·머리말·파일명에 함께 쓰인다 |
| `DATE` | 이 버전의 발행일 |
| `AUTHOR` | 저자 — **사용자에게 묻고 고정한다. 추측하지 않는다** |
| `AFFIL` | 소속 |

## 이 템플릿이 자동으로 하는 것

| 자리 | 내용 |
|---|---|
| **표지** | 제목 42 pt · 부제 21 pt · `버전 v0.0 · 발행일` 15 pt · **저자·소속 21 pt** · AI 사용 고지 14 pt · 표기 원칙 12 pt |
| **2쪽** | 「개정 이력」 (md 에 표로 쓴다) |
| **머리말** | 왼쪽 제목 / 오른쪽 `v버전 · 발행일` |
| **꼬리말** | 왼쪽 `저자 · 소속` / 오른쪽 **`n / N`** |
| **출처 앞** | 「AI 사용 내역」 (md 에 표로 쓴다) |
| **산출** | `.pptx` + **`.pdf`**(필수) — 페이지 수가 슬라이드 수와 같은지 검증 |
| **이력** | 이전 버전 **네 파일**을 `__history__/` 로 이동 (그 뒤 `_CHANGE.md` 는 사람이 쓴다) |

⛔ **발행일은 버전 줄에만 적는다.** 저자 아래에 또 적지 않는다.

## md 문법

| 쓰는 법 | 결과 |
|---|---|
| `# 제목` · `## 부제` · `@@ 메타` (첫 블록) | 표지 |
| `===` 한 줄 | 슬라이드 구분 |
| `## 제목` | 구분(섹션) 슬라이드 — 남색 띠 |
| `### 제목` | 본문 슬라이드 |
| `- 항목` / 두 칸 들여쓴 `- 항목` | 불릿 / 하위 불릿 |
| `\| a \| b \|` | 표 (첫 행은 머리글) |
| ` ``` ` 블록 | 회색 상자 + 고정폭 글꼴 (**쓴 순서대로** — 표 뒤에 쓰면 표 아래에 온다) |
| `> 출처: …` | 슬라이드 하단 출처 캡션 |
| `**굵게**` · `*기울임*` · `` `코드` `` | 런 단위 서식 |
| 빈 줄 없이 이어진 줄 | 앞 항목에 이어 붙는다 |

## 환경 의존

| 필요한 것 | 없으면 |
|---|---|
| `python3` + `python-pptx` (검증 1.0.2) | pptx 생성 불가 |
| LibreOffice `soffice` | **pdf 생성 불가 — 규칙상 미완으로 보고해야 한다** |
| 한글 서체 `Apple SD Gothic Neo` (macOS 기본) | 글자가 깨진다 (`FONT` 상수로 교체) |
