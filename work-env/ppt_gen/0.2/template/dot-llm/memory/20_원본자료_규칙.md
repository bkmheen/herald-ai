# 원본 자료 규칙

## 위치와 취급

- 원본은 `{{SOURCE_DIR}}/` 에만 둔다. 모든 LLM 이 여기서 읽는다.
- ⛔ **읽기 전용으로 취급한다.** 수정·삭제·이름 변경을 하지 않는다.
  원본이 없으면 아무것도 재생성할 수 없다.
- 가공한 결과물은 **자기 작업공간**(`<llm>/`)에 둔다.

## 입력 종류

| 종류 | 두는 법 | 다루는 법 |
|---|---|---|
| 이미지 묶음 | `{{SOURCE_DIR}}/<주제>/*.png` 등 | 순서가 의미를 가지면 파일명 순서를 흐름으로 본다 |
| PDF 문서 | `{{SOURCE_DIR}}/*.pdf` | 페이지 단위로 추출해 쓴다 |
| 기타 | `{{SOURCE_DIR}}/` 아래 주제별 폴더 | 종류가 늘면 이 표에 한 줄 더한다 |

## 가공 기록

원본을 가공했으면 **무엇을 왜 그렇게 했는지** 자기 작업공간에 남긴다.
가공 결과물마다 같은 이름의 `.md` 를 두는 방식을 권한다 — 나중에 검증할 수 있고,
다른 LLM 이 이어받을 때 판단 근거를 읽을 수 있다.

```
<llm>/work/step_001.png
<llm>/work/step_001.md     ← 원본 어느 파일에서 무엇을 어떻게 했나
```

## 제외 판단

원본 중 쓰지 않기로 한 것이 있으면 **지우지 말고 제외 사유를 기록**한다.

```
<llm>/work/_제외된_원본.md
```

⚠️ 축소판(썸네일)만 보고 판단하지 않는다. **원본 크기로 확인한 뒤** 제외한다.
흐릿해 보였던 것이 실제로는 선명한 경우가 있다.

## 이 프로젝트에서 추가로 정한 것

(원본 종류에 따른 가공 규칙, 가려야 하는 정보, 강조 규칙 등을 여기에 적는다.
규칙이 길어지면 별도 번호 파일로 분리하고 여기서 가리킨다.)
