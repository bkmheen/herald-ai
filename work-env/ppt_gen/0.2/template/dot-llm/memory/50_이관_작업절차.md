# 이관 작업절차 (Runbook)

> 옮기거나 복사하는 작업도 LLM 이 수행한다. **이 순서를 그대로 따른다.**

## A. 옮기기 전 — 정리 (출발지에서)

1. **작업물이 최신인지 확인한다.** 빌드가 필요한 구조면 돌려서 오류가 없는지 본다.
2. **버려야 하는 것을 지운다.**

```bash
find . -name ".DS_Store" -delete
find . -name "__pycache__" -type d -exec rm -rf {} +
find . -name ".omc" -type d -exec rm -rf {} +     # 도구 런타임 캐시 (절대경로가 박혀 있다)
```

3. **미완결 기록을 채운다** — `__history__/` 에 `_CHANGE.md` 가 빠진 버전,
   갱신 안 된 `STATUS.md` · `BOARD.md`.

## B. 복사 — 숨은 파일이 핵심

### 반드시 포함

| 대상 | 없으면 |
|---|---|
| `.llm/` | **기억이 전부 사라진다** (숨은 디렉토리라 빠지기 쉽다) |
| `CLAUDE.md` · `GEMINI.md` · `AGENTS.md` | LLM 이 아무것도 읽지 못한다 |
| `{{SOURCE_DIR}}/` | 아무것도 재생성할 수 없다 |
| `<llm>/` 작업공간과 `__history__/` | 산출물과 이력이 사라진다 |

### 제외해도 되는 것

가상환경 · 컴파일된 바이너리 · 검증용 중간 산출물 · `.omc/` · `__pycache__` · `.DS_Store`.
**재생성 방법을 문서에 남겨 둔 것만** 제외한다.

### 명령

```bash
rsync -a --exclude '.omc' --exclude '__pycache__' --exclude '.DS_Store' \
      "<출발지>/" "<도착지>/"
```

> ⛔ **Finder 드래그로 옮기지 않는다.** 숨은 파일 표시 설정에 따라 `.llm/` 이 빠질 수 있다.
> `rsync -a` 또는 `tar` 를 쓴다.

### 복사 직후 확인

```bash
cd "<도착지>"
ls -d .llm && find .llm -name "*.md" | wc -l     # 출발지와 같아야 한다
ls CLAUDE.md GEMINI.md AGENTS.md
ls {{SOURCE_DIR}}/ | wc -l
```

`.md` 개수로 비교한다. `.DS_Store` 는 macOS 가 계속 되살리고 복사에서 제외되므로
**전체 파일 수는 항상 다르게 보인다.**

**`.llm/` 이 없으면 멈추고 다시 복사한다.** 그대로 진행하면 기억 없이 일하게 된다.

## C. 도착지 환경 구성

프로젝트가 도구·서체·런타임에 의존하면 그 목록과 재생성 명령을 **각 작업공간의
`README.md` 에 적어 둔다.** 옮긴 뒤 그것을 따른다.

## D. 검증

1. **LLM 이 기억을 읽는지** — 도착지를 작업 디렉토리로 해서 실행하고 물어본다.
   "무엇을 먼저 읽었는가? 지금 어디까지 진행되었는가?"
   `.llm/BOARD.md` 와 `00_INDEX.md` 를 읽었다고 답하면 정상이다.
   아니면 상위 디렉토리에서 실행했거나 진입점 파일이 빠졌다.
2. **절대경로 잔여 확인** — 스크립트·문서에 출발지 경로가 남아 있지 않은지.
3. **재생성** — 빌드 구조면 돌려서 산출물이 같게 나오는지. 페이지 수·렌더를 대조한다.

## E. 주의

- **따라오지 않는 것** — 도구의 홈 디렉토리에 있는 전역 지침과 스킬은 이동하지 않는다.
  이 프로젝트에 필요한 부분은 진입점 문서와 `.llm/memory/` 에 복제해 둔다.
- **대화 원문은 이관 대상이 아니다.** 결론과 근거를 `.llm/sessions/` 에 남긴다.
- **기억 파일에 절대경로를 쓰지 않는다.** 한 줄만 있어도 이사하면 깨진다.
- **이관 성공을 확인하기 전까지 출발지를 지우지 않는다.**
- 옮긴 뒤 `.llm/sessions/YYYY-MM-DD_<도구>_이관.md` 에 결과를 기록한다.
