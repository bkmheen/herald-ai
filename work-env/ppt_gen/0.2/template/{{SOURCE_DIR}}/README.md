# {{SOURCE_DIR}} — 원본 자료

이 디렉토리는 **모든 LLM 이 공유하는 원본**이다.

## ⛔ 읽기 전용

수정·삭제·이름 변경을 하지 않는다. 원본이 없으면 아무것도 재생성할 수 없다.
가공한 결과물은 **각자의 작업공간**(`<llm>/`)에 둔다.

## 두는 법

| 종류 | 예 |
|---|---|
| 이미지 묶음 | `{{SOURCE_DIR}}/<주제>/IMG_0001.png` … (파일명 순서가 흐름이 된다) |
| PDF 문서 | `{{SOURCE_DIR}}/<제목>.pdf` |
| 기타 | 주제별 폴더를 만들어 둔다 |
