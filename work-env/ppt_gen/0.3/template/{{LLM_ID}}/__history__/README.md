# 버전 이력

## 규칙

- 이 작업공간에는 **최종 버전 한 벌만** 둔다.
- 새 버전이 나오면 이전 버전의 산출물 파일을 이 디렉토리로 옮긴다.
- 버전마다 `<산출물 이름>_v<버전>_CHANGE.md` 로 **직전 버전과의 차이**를 남긴다.

상세: `.llm/memory/30_산출물_및_버전_규칙.md`

## `_CHANGE.md` 에 적을 것

```markdown
# <산출물 이름> — v1.0

- 날짜: YYYY-MM-DD
- 직전 버전: v0.9
- 요약: (한 줄)

## v0.9 대비 변경 내용

- 무엇이 바뀌었나 — 그리고 **왜 바꿨나**
```

**왜 바꿨나를 빠뜨리지 않는다.** 그것이 다음 판단의 근거가 된다.
