## 세션 시작 시 반드시 할 일

**어떤 답을 하기 전에** 이 순서로 읽는다.

1. `.llm/BOARD.md` — **누가 어디까지 했는가.** 이어받을 지점이 여기 적혀 있다.
2. `.llm/memory/00_INDEX.md` — 공용 기억 색인. 가리키는 순서대로 읽는다.
3. `.llm/agents/claude/memory/00_INDEX.md` — 내 개별 기억 (있으면).
4. 내 작업공간의 `STATUS.md` — 내가 직전에 어디까지 했는가.

읽은 뒤 사용자에게 **"어디까지 진행되었는지" 한두 줄로 확인**시키고 이어서 작업한다.

## 기억과 기록은 이 디렉토리 안에만 남긴다

| 쓸 곳 | 무엇을 |
|---|---|
| `.llm/memory/` | **모든 LLM 이 공유할** 사실 — 프로젝트 맥락, 사용자 지시, 규칙, 판단 근거 |
| `.llm/agents/claude/memory/` | **나만의** 기억 — 내 구현 방식, 내가 겪은 함정 |
| `.llm/sessions/` | 공용 세션 기록 (다른 LLM 도 읽어야 하는 것) |
| `.llm/agents/claude/sessions/` | 내 세션 기록 |
| `.llm/BOARD.md` | 작업을 마칠 때마다 **내 줄을 갱신** |
| `claude/STATUS.md` | 내 작업공간의 현재 상태 |

⛔ **홈 디렉토리(`~/.claude`)에는 이 프로젝트의 기억을 남기지 않는다.**
이 디렉토리를 다른 컴퓨터로 옮겨도 기억이 따라가야 하기 때문이다.
작성 규칙은 `.llm/README.md` 에 있다.

## 번호 규칙

자료마다 두 자리 번호를 붙이고 **한 디렉토리에서 하나의 숫자는 하나의 자료만** 가리킨다.
번호는 디렉토리를 가로질러 같은 자료를 가리키므로, "03" 이라고만 해도 입력·스크립트·
산출물이 한꺼번에 지목된다.

```
{{SOURCE_DIR}}/03. <제목>/            입력
{{LLM_ID}}/03. <제목>.py              생성 스크립트
{{LLM_ID}}/03. <제목>_v1.0.pptx       산출물
```

- 자료는 `NN. 제목` (점 + 공백) · 기억·규칙 문서는 `NN_제목.md` (밑줄)
- `90`~`99` 는 특별 코드 — 규칙 정본·메타 문서 (자료가 아닌 것). `00` 은 전체 색인·요약
- 번호를 **재사용하지 않는다.** 자료를 빼도 비워 둔다
- ⛔ **번호에는 의미가 없다.** 순서·중요도를 뜻하지 않는다
- ⛔ **번호는 문서 내부에 들어가지 않는다.** 표지·본문에 `03` 을 쓰지 않고, 다른 자료를
  번호로 참조하지 않는다. **각 자료는 독립 문서다**

상세: `.llm/memory/25_번호_규칙.md`

## 산출물 규칙

파일명 끝에 버전을 붙이고, **최종 버전 한 벌만** 작업공간에 둔다.

```
claude/<번호>. <제목>_v1.0.pptx
claude/__history__/<번호>. <제목>_v0.9.pptx        ← 이전 버전은 여기로
claude/__history__/<번호>. <제목>_v1.0_CHANGE.md   ← 직전 버전 대비 변경 내용
```

상세: `.llm/memory/30_산출물_및_버전_규칙.md`

## 응대 원칙

- 존댓말, 정중한 비서 어투. 사용자의 유급 비서로서 목적까지 고려해 응대한다.
- ⛔ **원 문자 금지** — `①②③`, `⑴`, `ⓐ` 등을 쓰지 않는다. `(1) (2) (3)` 으로 쓴다.
- **원인을 단정하지 않는다.** 확인되지 않은 추정은 쓰지 않고 관찰된 사실만 적는다.
- 결과 보고는 사실 그대로. 실패·미완을 숨기지 않는다.
- 작업 시작·종료 시 `task-tracker` 스킬이 있으면 호출한다 (없는 컴퓨터에서는 건너뛴다).
