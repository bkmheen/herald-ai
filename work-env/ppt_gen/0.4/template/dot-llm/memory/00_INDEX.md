## 3단계 — 내 개별 기억

`../agents/<내 이름>/memory/00_INDEX.md` (있으면)

## 4단계 — 필요할 때만

- `../sessions/` — 공용 세션 기록. "왜 이렇게 되어 있나" 를 알아야 할 때
- `../agents/<llm>/` — 그 LLM 의 기억. 이어받을 때
- `<llm>/__history__/` — 산출물 버전별 변경 기록
