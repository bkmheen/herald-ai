# {{LLM_ID}} 작업공간

이 디렉토리는 **{{LLM_ID}} 의 자리**다. 다른 LLM 은 여기를 **읽기만** 한다.

## 구조

```
{{LLM_ID}}/
├── README.md               이 파일 — 이 작업공간의 사용법과 환경 의존
├── STATUS.md               ★ 현재 상태. 작업을 마칠 때마다 갱신한다
├── <번호>. <제목>.py         자료별 생성 스크립트 (코드로 만드는 경우)
├── <번호>. <제목>_v<버전>.pptx  최종 버전 한 벌만
└── __history__/            이전 버전 + _CHANGE.md
```

번호는 `{{SOURCE_DIR}}/` 의 자료 번호를 그대로 쓴다 — 같은 번호가 입력·스크립트·산출물을
한꺼번에 가리키게 하는 것이 목적이다 (`.llm/memory/25_번호_규칙.md`).

작업 중 만드는 중간 산출물은 하위 디렉토리를 만들어 둔다 (예: `work/` · `build/`).
**지워도 되는 것**과 **반드시 보존할 것**을 이 README 에 구분해 적는다.

## 환경 의존

이 작업공간을 다른 컴퓨터에서 쓰려면 필요한 것을 여기에 적는다.
적어 두지 않으면 옮긴 뒤 재현할 수 없다.

| 필요한 것 | 버전·설치 방법 | 없으면 |
|---|---|---|
| (예) python3 + 패키지 | `requirements.txt` 로 재생성 | 빌드 불가 |
| (예) 서체 | 환경변수로 교체 가능하게 | 글자가 깨진다 |

## 재생성 방법

```
(여기에 산출물을 다시 만드는 명령을 적는다. 프로젝트 루트 기준 상대경로로 쓴다)
```

⛔ **스크립트에 절대경로를 하드코딩하지 않는다.** 자기 파일 위치에서 유도한다.
그러지 않으면 디렉토리를 옮기는 순간 동작하지 않는다.
