# {{PROJECT_NAME}} — 이 프로젝트에서 일하는 방법

> AGENTS.md 규약을 쓰는 도구(Codex 등) 은 작업 디렉토리의 `AGENTS.md` 를 자동으로 읽는다.
> 이 프로젝트의 지침은 도구와 무관하게 하나로 관리한다.

## 먼저 읽을 것

**같은 디렉토리의 `CLAUDE.md` 내용을 그대로 따른다.** 도구 이름만 다르고 규칙은 동일하다.

순서를 요약하면 이렇다.

1. `.llm/BOARD.md` — 누가 어디까지 했는가. 이어받을 지점
2. `.llm/memory/00_INDEX.md` — 공용 기억 색인
3. `.llm/agents/codex/memory/00_INDEX.md` — 내 개별 기억 (있으면)
4. `codex/STATUS.md` — 내 작업공간의 현재 상태

## 사용자가 "진행기록" 이라고 하면

`.llm/PROGRESS.md` 를 날짜별로 갱신하는 작업이다. 새 파일을 만들지 않는다.
쓰기 전에 `.llm/memory/45_진행기록_작성법.md` 를 읽는다.

- 작성 규칙은 `.llm/README.md`

## 번호 규칙

자료마다 두 자리 번호를 붙이고 **한 디렉토리에서 하나의 숫자는 하나의 자료만** 가리킵니다.
번호는 디렉토리를 가로질러 같은 자료를 가리키므로 "03" 이라고만 해도 입력·스크립트·산출물이
한꺼번에 지목됩니다.

```
{{SOURCE_DIR}}/03. <제목>/       입력
{{LLM_ID}}/03. <제목>_v1.0.py    생성 스크립트
{{LLM_ID}}/03. <제목>_v1.0.pptx  산출물 (+ .pdf · .md 동명)
```

- 자료는 `NN. 제목` (점 + 공백) · 기억·규칙 문서는 `NN_제목.md` (밑줄)
- `90`~`99` 는 특별 코드 — 규칙 정본·메타 문서. `00` 은 전체 색인·요약
- 번호를 **재사용하지 않습니다.** 자료를 빼도 비워 둡니다
- ⛔ **번호에는 의미가 없습니다.** 순서·중요도를 뜻하지 않습니다
- ⛔ **번호는 문서 내부에 들어가지 않습니다.** 표지·본문에 `03` 을 쓰지 않고, 다른 자료를
  번호로 참조하지 않습니다. **각 자료는 독립 문서입니다**

상세: `.llm/memory/25_번호_규칙.md`

## 산출물 규칙

**한 산출물은 이름이 같은 파일 네 개입니다.** 확장자만 다르고 번호·제목·버전은 완전히 같습니다.

```
{{LLM_ID}}/<번호>. <제목>_v1.0.pptx     산출물 본체
{{LLM_ID}}/<번호>. <제목>_v1.0.pdf      ★ 항상 함께 만듭니다 (선택 아님)
{{LLM_ID}}/<번호>. <제목>_v1.0.md       슬라이드 내용 원본 (열지 않고 읽습니다)
{{LLM_ID}}/<번호>. <제목>_v1.0.py       생성 스크립트 (코드로 만드는 경우)
```

- ⛔ **pdf 가 없는 상태를 "완료" 라고 보고하지 않습니다.** 변환 도구가 없으면 그 사실을 알립니다
- pdf 변환: `soffice --headless --convert-to pdf --outdir <디렉토리> "<파일>.pptx"`
- 이전 버전은 **네 파일을 함께** `{{LLM_ID}}/__history__/` 로 옮기고 `_CHANGE.md` 를 남깁니다

상세: `.llm/memory/30_산출물_및_버전_규칙.md`
