# {{SOURCE_DIR}} — 사용자 자료

**사용자가 포함한 자료**를 두는 디렉토리다. LLM 은 읽기만 한다.

LLM 이 만들거나 모은 자료는 여기가 아니라 `reference/` 에 둔다 (기록을 남기는 조건으로
LLM 이 자체 관리한다).

## ⛔ 읽기 전용

수정·삭제·이름 변경을 하지 않는다. 원본이 없으면 아무것도 재생성할 수 없다.
가공한 결과물은 **각자의 작업공간**(`<llm>/`)에 둔다.

## 두는 법

**자료마다 두 자리 번호를 붙인다** — `NN. <제목>`. 그 번호가 이 자료를 가리키는 이름표가
되어 `reference/` 의 재료와 작업공간의 스크립트·산출물까지 같은 번호를 쓴다.

| 종류 | 예 |
|---|---|
| 이미지 묶음 | `{{SOURCE_DIR}}/01. <제목>/IMG_0001.png` … (파일명 순서가 흐름이 된다) |
| PDF 문서 | `{{SOURCE_DIR}}/02. <제목>.pdf` |
| 기타 | 번호를 붙인 주제별 폴더를 만들어 둔다 |

한 디렉토리에서 **하나의 숫자는 하나의 자료만** 쓴다. 자료를 빼도 번호를 재사용하지 않는다.
번호에는 의미가 없고 문서 내부에도 들어가지 않는다 — `.llm/memory/25_번호_규칙.md`.
