# ha-we-ppt_gen v0.8

- 일자: 2026-09-30
- 이전: v0.7

## 무엇이 바뀌었나

**표지 사양을 다듬었다.** v0.7 이 세운 공통 골격은 유지하고, 표지 블록의 **중복과 크기**만 고쳤다.

| 항목 | v0.7 | **v0.8** |
|---|---|---|
| 발행일 | 버전 줄과 저자 아래 **두 곳** | **버전 줄에만** |
| 저자·소속 | 크기 미지정 | **21 pt** (부제와 같은 무게) |
| AI 사용 고지 | 크기 미지정 | **14 pt** |
| 표기 원칙 | 크기 미지정 | **12 pt** |

`manifest.json` 의 `deliverable.layout.cover` 에도 같은 내용을 반영했다.

## 왜 바꿨나

**같은 정보가 표지에 두 번 나왔다.** 부제 아래 `버전 v0.0 · 2026-09-30` 이 있는데 저자 아래에도
`2026-09-30` 이 있었다. 버전과 날짜는 **한 쌍으로 읽히는 정보**이므로 버전 줄이 함께 맡는 것이
자연스럽다. 저자 블록은 **저자 → 도구 고지 → 표기 원칙** 세 줄로 간결해진다.

**크기를 명시한 이유.** v0.7 은 "무엇을 적을지" 만 정하고 "얼마나 크게" 를 비워 두었다.
그 결과 저자·소속이 각주 크기로 놓여 **표지에서 두 번째로 중요한 정보가 눈에 들어오지 않았다.**
제목 42 → 부제 21 → **저자 21** → 14 → 12 로 계단을 만들면 **읽는 순서가 저절로 정해진다.**

## 이관 시 주의

v0.7 이하로 만든 디렉토리에 v0.8 을 다시 뿌려도 **기존 파일은 덮지 않는다**(멱등).
`.llm/memory/30_산출물_및_버전_규칙.md` 의 「(1) 표지」 절을 손으로 옮긴다.
이미 만든 pptx 에 발행일이 두 번 나오면 **다음 버전을 올릴 때 함께 고친다.**
