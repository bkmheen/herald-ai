## 디렉토리 구조

```
<프로젝트 루트>/
├── CLAUDE.md · GEMINI.md · AGENTS.md   각 도구의 자동 로드 진입점
├── {{SOURCE_DIR}}/         사용자 자료 (읽기 전용)
├── reference/              LLM 이 만들거나 모은 자료 (기록 조건부 관리)
├── .llm/                   LLM 공용 기억·기록·현황판
│   ├── BOARD.md            누가 어디까지 했는가
│   ├── memory/             공용 기억
│   ├── sessions/           공용 세션 기록
│   └── agents/<llm>/       LLM 개별 기억·기록
└── <llm>/                  LLM 별 작업공간 (산출물 + 생성 스크립트)
    ├── STATUS.md
    └── __history__/        산출물 버전 이력
```

**여러 LLM 이 같은 원본으로 각자 만들어 비교하고, 필요하면 이어받는다.**
상세 규칙은 [`40_LLM_협업_규칙.md`](40_LLM_협업_규칙.md).
